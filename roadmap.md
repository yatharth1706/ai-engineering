# AI Engineering Roadmap

## Goal

Move from Full-Stack/Backend SWE → AI FDE / Applied AI / Full-Stack AI Engineer.

## Chapters

### 01 — LLM Engineering
- Tokens, context windows, messages, temperature, streaming, token usage, cost/latency, model selection
- Build: **AI Playground**

### 02 — RAG
- Embeddings, chunking, vector search, pgvector, retrieval, citations
- Build: **Engineering Knowledge AI**

### 03 — AI Agents
- Tool calling, agent loops, state, memory, planning
- Build: **AI SDR Agent**

### 04 — AI Evals
- Evaluation datasets, LLM-as-judge, regression testing, hallucination testing
- Build: **AI Evaluation System**

### 05 — Reliable AI Workflows
- Durable execution, retries, idempotency, human-in-the-loop, long-running workflows
- Build: **Durable AI Workflow**

### 06 — AI Infrastructure
- Model routing, fallbacks, caching, rate limiting, cost tracking, observability
- Build: **AI Gateway**

### 07 — Multimodal AI
- Vision, audio, transcription, document understanding, MCP
- Build: **Meeting Intelligence**

### 08 — Capstone
- Build: **AI Revenue Engineer**
